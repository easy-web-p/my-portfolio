# Small Language Models in Browser: Phi-3 Mini & WebGPU

Can a 3.8B quantized model run zero-latency semantic search entirely inside WebGPU without cloud roundtrips? Here is our unfiltered research log.

## Hypothesis
Cloud API roundtrips introduce anywhere from 400ms to 2,000ms latency, breaking fluid micro-interactions. If small models can execute locally in VRAM via WebGPU, interfaces can achieve sub-50ms reactive feedback loops.

## Test Results
- **Safari on Apple Silicon (M2)**: Sustained 48 tokens/sec using WebLLM.
- **Chrome on Android**: 22 tokens/sec on high-end Snapdragon devices.
- **Context degradation**: Past 1,800 tokens, quantized attention degradation leads to subtle hallucinations in UI component schemas.
